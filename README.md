# SEAMATH 

a mathematics assist development environment based on SEA

# What is SEA 
 an extension of C language allowing vectorialisation and direct variable instanciate (eg a = 2, v= {1,2}) 

# List of projects
- GateCLang:    project for management of C/(C++ planned) source code.
- GateDock:     Dockable widget base assembly based on Windows Forms.
   - GatePad a text editor based on Scintilla\Scintilla.NET\GateDock 
- GateTools:    Base tool library shared among all projects.
- Scintilla:    Customisation of https://www.scintilla.org/SciTE.html source code.
- ScintillaNet: Customisation of https://github.com/jacobslusser/ScintillaNET
- SeaChecks     coding rule checker base on GateCLang
- SeaMath:      script oriented language suitable for Mathematics (based on GateCLang)

## Compilation instrucions:
  - open SeaMath.sln on repository root
  - select GatePad as sturtup project and compile
  - launch GatePad (includes seamath as a plug-in)
